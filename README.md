# Playerok Garant — Blue 3D

Telegram Mini App с голубо-синим объёмным интерфейсом.

## Render
- Runtime: Node 22 (указан в `package.json`)
- Build Command: `npm install`
- Start Command: `npm start`
- Environment:
  - `BOT_TOKEN` — токен от BotFather (секрет, не публиковать)
  - `APP_URL` — точный публичный HTTPS адрес Render без `/` в конце
  - `ADMIN_IDS` — числовые Telegram ID главных администраторов через запятую
  - `DATA_DIR` — каталог данных приложения, например `/var/data` при подключённом persistent disk
  - `DATABASE_PATH` — полный путь к SQLite, например `/var/data/playerok-garant.sqlite`

## Важно для Render
Без `APP_URL` бот не выдаёт демонстрационную ссылку `example.com`, а сообщает, что приложение ещё не настроено. После изменения `APP_URL` перезапустите сервис и обновите URL кнопки Menu Button в BotFather.

Важно: на Free Web Service Render нет Persistent Disk, сервис засыпает после 15 минут без входящего трафика, а локальные файлы (включая SQLite и загруженные фото) теряются при засыпании, перезапуске и деплое. Для SQLite на диске нужны платный Web Service + Persistent Disk (mount path `/var/data`, `DATA_DIR=/var/data`, `DATABASE_PATH=/var/data/playerok-garant.sqlite`). Альтернатива — вынести БД во внешнюю управляемую PostgreSQL и адаптировать приложение под неё.

## Установка
```bash
npm install
npm run check
npm start
```

## Возможности
- Голубо-синий 3D UI, адаптивная нижняя навигация и плавающие NFT-подарки.
- Создание сделки: роль покупателя/продавца, ссылка товара, username партнёра, сумма/валюта, необязательное описание, ручное или автоматическое приглашение.
- Присоединение по ссылке с выбором противоположной роли.
- Отмена сделки любой стороной до оплаты; после оплаты отмена требует проверки администратора.
- Подтверждение передачи фото, подтверждение получения покупателем, очередь админ-проверки.
- Профиль из Telegram: фото, username, баланс, отзывы и рейтинг.
- Админ-панель: выдача/отзыв админ-доступа, внутренняя корректировка баланса, управление розыгрышами, проверка сделок.
- Ежедневная внутренняя награда 23,1 RUB.

## Безопасность и ограничения
- Telegram `initData` проверяется серверной подписью; в production обход авторизации запрещён.
- Админ-права главных администраторов задаются только через `ADMIN_IDS`; администраторы могут назначать/отзывать дополнительных администраторов.
- Баланс и ежедневная награда — внутренний учёт, не реальные деньги. Реальные платежи, депозиты и выплаты не подключены. Не отмечайте оплату без подтверждения платёжного провайдера.
- Автоматическое приглашение возможно только если пользователь уже запускал бота и его Telegram ID известен; иначе отправьте ему ссылку вручную.
- Для настоящих выплат, возвратов и хранения средств нужна платёжная интеграция, юридическая проверка и защищённый арбитраж.
